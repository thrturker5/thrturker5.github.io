Chuby Buby Automation

A private channel-management tool for the Chuby & Buby YouTube channel, which publishes original, cozy, wordless animated films for young children and families.

What it does

Chuby Buby Automation runs on the channel owner's own computer and is used only by the channel owner. With the owner's permission, granted through Google sign-in, it:

  • reads the channel's video list and statistics (views, likes, subscribers) using the YouTube Data API;
  • reads the channel's YouTube Analytics reports (watch time, audience retention, traffic sources) using the YouTube Analytics API;
  • stores that history locally and writes a daily performance report for the owner;
  • keeps a local queue of videos the owner has made and approved and, only after separate explicit permission, uploads them to the owner's channel with a scheduled publication time.

It never edits or deletes existing videos, never reads anyone else's data, and is not offered to the public.
